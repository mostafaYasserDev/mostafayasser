## 🎨 القواعد التوجيهية للذكاء الاصطناعي (AI Prompt Guide):

عند طلب إنشاء أو تعديل أي قالب بريد إلكتروني، يجب الالتزام بالمعايير التالية بدقة:

### 1. الألوان والهوية البصرية:
- **الخلفية الأساسية (Background):** `#f8f6f0` (درجة بيج دافئة وأنيقة)
- **بطاقة المحتوى (Card / Container):** `#ffffff` مع حواف مستديرة `border-radius: 16px;` وحد خفيف `#e8e2d8`.
- **اللون الأساسي (Primary Earth Brown):** `#5c3d2e`
- **اللون الثانوي (Forest Green Accent):** `#2e7d32` أو `#4a6b48`
- **لون النص الأساسي:** `#2c2523`
- **لون النص الثانوي (Muted Text):** `#6b635b`

### 2. التوافق والتقنية (HTML Email Best Practices):
- استخدام جدول أحادي الحاوية (`<table width="100%" cellpadding="0" cellspacing="0">`) لضمان التوافق مع كافة برامج البريد (Gmail, Apple Mail, Outlook).
- التنسيقات مضمنة (Inline CSS) مع استخدام خطوط واضحة تدعم اللغة العربية والإنجليزية (مثل: `Cairo`, `Segoe UI`, `Tahoma`, `sans-serif`).
- اتجاه النص `dir="rtl"` للرسائل العربية أو `dir="ltr"` للإنجليزية، مع استخدام `dir="ltr"` للأرقام والروابط والبريد الإلكتروني.

### 3. هيكل الرسالة النموذجي:
- **Header:** شعار جذع واسم المرسل بتنسيق راقٍ.
- **Hero / Hook:** تحية شخصية واضحة ومقدمة موجزة وجذابة.
- **Value Cards:** بطاقات مميزة تعرض الإنجازات، المشاريع السابقة، والحلول المقترحة.
- **Call-to-Action (CTA):** زر تفاعلي واضح بلون متباين ومقاس كبير (`border-radius: 10px; padding: 14px 28px;`).
- **Footer:** روابط التواصل الاجتماعي، البريد الإلكتروني، وتوقيع المصادقة.
